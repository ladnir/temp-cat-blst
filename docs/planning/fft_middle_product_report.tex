\section{Scope}
This report compares full and truncated FFT/iFFT kernels and their integration into middle-product flows.
Reader assumption: familiarity with FFT and middle-product algorithms.

Compared middle-product variants:
\begin{enumerate}
\item basic FFT + basic iFFT
\item basic FFT + truncated iFFT
\item truncated FFT + truncated iFFT (pruned basic)
\item specialized middle product
\item specialized middle product + truncation
\end{enumerate}

\section{Benchmark Setup}
\begin{itemize}
\item Range: \(n \in \{64,96,\ldots,512\}\) (step 32, non-power-of-two included).
\item Input shape: \(A\) has \(n\) coefficients in \(G_1\), \(B\) has \(2n\) coefficients in \(G_2\).
\item FFT length for basic path: \(m = 2^{\lceil \log_2(3n-1) \rceil}\).
\item Standalone kernel runs: 3 repetitions, mean reported.
\item Integrated middle-product runs: 1 repetition per \(n\) (long-running pairings).
\item Timings are real-time milliseconds from Google Benchmark JSON outputs in \texttt{docs/planning/*.json}.
\end{itemize}

\section{Savings Summary}
\begin{itemize}
\item Standalone forward FFT truncation average savings: 3.8\%.
\item Standalone inverse FFT truncation average savings: -5.8\%.
\item Integrated basic path (truncated iFFT vs basic baseline): 14.8\% average savings.
\item Integrated pruned basic path (truncated FFT+iFFT vs basic baseline): -8.1\% average savings.
\item Specialized truncated vs specialized baseline: 10.8\% average savings.
\end{itemize}

\section{Interpretation}
\begin{itemize}
\item Forward truncation in \(G_1\) gives a modest positive average win, with clear size-dependent variability.
\item Standalone truncated iFFT (prefix form) is mixed in this sweep and is slightly negative on average by itself.
\item In the integrated basic middle-product flow, adding truncated iFFT is still a strong net positive.
\item The current pruned-basic implementation is not yet a net win over basic+truncated-iFFT and needs further kernel/layout tuning.
\item Specialized+trunc improves over specialized baseline and is the preferred specialized variant in this sweep.
\item Size transitions where \(m\) doubles remain visible; non-power-of-two \(n\) values are still important for policy tuning.
\end{itemize}
