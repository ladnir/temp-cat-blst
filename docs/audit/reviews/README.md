# File Review Records

Create one stable Markdown record per reviewed file from
`../FILE_REVIEW_TEMPLATE.md`.

Encode the repository path by replacing `/` with `__`, for example:

```text
blst__backend__backend_portable.cpp.md
bindings__rust__src__lib.rs.md
```

If a file is renamed, retain the old record and link it from the new record.
Do not overwrite historical evidence or reuse a review record for unrelated
content.
